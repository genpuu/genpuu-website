# 相続した空き家を売ると最大3,000万円の控除！知らないと損する特例とは

相続した実家を売却すると、売却益（譲渡所得）に対して所得税・住民税がかかります。しかし、一定の要件を満たせば、譲渡所得から**最大3,000万円を控除**できる特例があることをご存じでしょうか。

この特例を知っているかどうかで、税額に**数百万円の差**が出ることもあります。この記事では、「被相続人の居住用財産（空き家）に係る譲渡所得の特別控除の特例」について、要件と注意点をわかりやすく解説します。

---

## 空き家の3,000万円特別控除とは？

正式には「被相続人の居住用財産（空き家）に係る譲渡所得の特別控除の特例」といいます。

亡くなった方が一人で住んでいた自宅（空き家）を相続人が売却する場合、一定の要件を満たせば**譲渡所得から最大3,000万円を差し引く**ことができます。

### 具体例

- 実家の売却価格：2,500万円
- 取得費（購入時の価格）：不明のため売却価格の5%＝125万円
- 譲渡費用（仲介手数料等）：100万円
- 譲渡所得：2,500万円 − 125万円 − 100万円 ＝ **2,275万円**

特例を使わない場合、この2,275万円に対して約20%（長期譲渡所得の場合）の税金がかかり、約**455万円**の税負担になります。

特例を使えば、2,275万円 − 3,000万円 ＝ マイナスとなり、**税金はゼロ**です。

455万円の差は非常に大きいですよね。

## 適用要件を確認しましょう

この特例には細かい要件があります。一つでも満たしていないと適用できませんので、しっかり確認しましょう。

### 要件1：建物に関する条件

- **昭和56年（1981年）5月31日以前に建築**された建物であること
- 相続開始の直前において、**被相続人が一人で居住**していたこと（老人ホーム入居の場合は一定の要件で認められる）
- マンションなどの区分所有建物ではないこと

昭和56年5月31日は、建築基準法の**新耐震基準**が施行された日です。それ以前の建物、つまり旧耐震基準の建物が対象ということです。

### 要件2：売却に関する条件

- **相続の開始があった日から3年を経過する日の属する年の12月31日まで**に売却すること
- 売却価格が**1億円以下**であること
- 売却先が親族など特別な関係者でないこと

### 要件3：建物の状態に関する条件

売却時に以下のいずれかを満たしている必要があります。

- **耐震リフォーム**を行い、現行の耐震基準に適合させた上で建物ごと売却する
- 建物を**取り壊して更地**にしてから売却する
- 買主が取壊しまたは耐震リフォームを行うこと（令和6年1月1日以降の譲渡）

旧耐震基準の建物をそのままの状態で売却しても、この特例は使えません。耐震基準に適合させるか、解体して更地にする必要があります。

令和6年1月1日以降は、売却後に**買主側で**取り壊しや耐震リフォームを行う場合でも適用可能になりました。この改正により、売主が解体費用を負担しなくても特例を使える道が開けました。

## 令和6年からの改正点に注意

### 相続人3人以上は控除額が2,000万円に縮小

令和6年1月1日以降の譲渡から、相続人が**3人以上**の場合は控除額が**2,000万円**に縮小されました。

- 相続人1〜2人：控除額 **3,000万円**
- 相続人3人以上：控除額 **2,000万円**

兄弟姉妹が多い場合はご注意ください。

### 適用期限は令和9年（2027年）12月31日まで

この特例には期限があり、現在は**令和9年（2027年）12月31日までの売却**が対象です。期限を過ぎると特例は使えなくなります（今後の延長の可能性はありますが、確定ではありません）。

## 確定申告が必要です

この特例を使うためには、売却した翌年に**確定申告**を行う必要があります。申告時に必要な書類は以下のとおりです。

- 譲渡所得の内訳書
- 被相続人居住用家屋等確認書（市区町村で発行）
- 登記事項証明書
- 売買契約書の写し
- 耐震基準適合証明書（耐震リフォームの場合）または取壊し後の更地であることが確認できる書類

特に「被相続人居住用家屋等確認書」は市区町村役場で発行してもらう必要がありますので、早めに手配しておきましょう。

## 他の特例との併用について

### マイホームの3,000万円控除との関係

自分が住んでいた家を売る場合の「居住用財産の3,000万円特別控除」とは別の制度です。空き家の特例と居住用の特例は、それぞれ別の物件について使うことが可能です。

### 相続税の取得費加算との関係

相続税を支払った方は、相続税の一部を取得費に加算できる「相続税の取得費加算の特例」がありますが、**空き家の3,000万円控除とは併用できません**。どちらか有利なほうを選択することになります。

多くの場合は3,000万円控除のほうが有利ですが、相続税額が大きい場合は取得費加算のほうが得になるケースもあります。税理士に試算してもらうことをおすすめします。

## まとめ

| 項目 | 内容 |
|---|---|
| 控除額 | 最大3,000万円（相続人3人以上は2,000万円） |
| 対象建物 | 昭和56年5月31日以前建築、被相続人が一人で居住 |
| 売却期限 | 相続開始から3年経過年の12月31日まで |
| 売却価格 | 1億円以下 |
| 建物の条件 | 耐震基準適合または取壊し済（買主対応も可） |
| 制度の期限 | 令和9年12月31日まで |
| 確定申告 | 必要 |

「親の実家が空き家になっている」「そろそろ売却を考えている」という方は、この特例の適用期限や要件を早めに確認されることをおすすめします。
