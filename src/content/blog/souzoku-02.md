# 親が亡くなったら何をすればいい？相続手続きの期限とやることリスト

大切なご家族を亡くされた直後は、悲しみの中で葬儀や諸手続きに追われ、何から手をつけてよいか分からなくなるものです。

しかし、相続に関する手続きには**厳格な期限**があります。期限を過ぎると、本来受けられるはずの権利を失ったり、余計な税金を支払うことになったりする場合もあります。

この記事では、親御さんが亡くなったあとに必要な手続きを、期限ごとに整理してお伝えします。このリストを手元に置いて、一つずつ確認していただければ幸いです。

---

## 【7日以内】死亡届の提出

ご家族が亡くなったことを知った日から**7日以内**に、市区町村役場へ死亡届を提出します。死亡届は死亡診断書とセットになっており、医師が記載した死亡診断書を添えて届け出ます。

届出先は、亡くなった方の本籍地・届出人の所在地・死亡地のいずれかの市区町村役場です。福岡市の場合は各区役所の市民課で受け付けています。

死亡届を出すと、同時に火葬許可証が交付されます。葬儀社が代行してくれるケースが多いですが、届出自体は遺族の方の責任で行うものです。

## 【14日以内】各種届出

### 年金受給権者死亡届

亡くなった方が年金を受給していた場合、**14日以内**（国民年金）または**10日以内**（厚生年金）に「年金受給権者死亡届」を年金事務所へ提出します。届出が遅れて年金が振り込まれ続けると、後日返還を求められますのでご注意ください。

なお、日本年金機構にマイナンバーが収録されている場合は届出を省略できるケースもあります。

### 健康保険・介護保険の資格喪失届

国民健康保険や後期高齢者医療制度に加入していた場合は、**14日以内**に市区町村役場へ資格喪失届を提出し、保険証を返却します。介護保険の資格喪失届も同様です。

### 世帯主変更届

亡くなった方が世帯主だった場合、**14日以内**に世帯主変更届を市区町村役場に提出します。ただし、残りの世帯員が1人だけの場合は届出不要です。

## 【3ヶ月以内】相続放棄・限定承認

相続では、プラスの財産（預貯金や不動産）だけでなく、**マイナスの財産（借金や連帯保証債務）も引き継ぎます**。

借金が多い場合は、「自分が相続人になったことを知ったときから**3ヶ月以内**」に家庭裁判所へ**相続放棄**の申述をすることで、一切の相続を放棄できます。

また、プラスの財産の範囲内でマイナスの財産を引き継ぐ**限定承認**という方法もありますが、相続人全員で行う必要があるため、実務上はあまり利用されていません。

3ヶ月はあっという間に過ぎます。亡くなった方に借金がないかどうか、早めに確認しましょう。信用情報機関（CIC・JICC・全銀協）に開示請求をすることで、借入状況を調べることができます。

## 【4ヶ月以内】準確定申告

亡くなった方にその年の所得があった場合、相続人が代わりに確定申告を行います。これを**準確定申告**といい、相続の開始を知った日の翌日から**4ヶ月以内**に税務署へ申告・納付しなければなりません。

対象となるのは、たとえば以下のようなケースです。

- 不動産の賃貸収入があった
- 事業を営んでいた
- 年金収入が一定額以上あった（年400万円超など）
- 2ヶ所以上から給与を受けていた

## 【10ヶ月以内】相続税の申告・納付

遺産の総額が基礎控除額（3,000万円＋600万円×法定相続人の数）を超える場合、相続の開始を知った日の翌日から**10ヶ月以内**に相続税の申告と納付が必要です。

10ヶ月は長いようで短いです。遺産の全容把握、不動産の評価、遺産分割協議、申告書の作成……これらを10ヶ月以内に終わらせるには、早めに税理士へ相談することが重要です。

なお、**小規模宅地等の特例**や**配偶者の税額軽減**など、税額を大幅に減らせる特例を使うためには、期限内に申告することが条件となっています。申告が遅れるとこれらの特例が使えなくなりますので、十分ご注意ください。

## 【1年以内】遺留分侵害額請求

遺言書の内容が偏っていて、法律で保障された最低限の取り分（遺留分）すら受け取れない場合、**遺留分侵害額請求**を行うことができます。

この請求権は、**相続の開始と遺留分侵害を知ったときから1年以内**に行使しないと時効により消滅します（民法第1048条）。また、相続開始から10年を経過しても消滅します。

遺言書の内容に納得がいかない場合は、早めに弁護士に相談されることをおすすめします。

## 【3年以内】相続登記

2024年4月からの義務化により、不動産を相続で取得したことを知ったときから**3年以内**に相続登記を申請しなければなりません。正当な理由なく期限を過ぎると、10万円以下の過料が科される可能性があります。

詳しくは本シリーズ第1回「相続登記の義務化とは？」をご覧ください。

## やることリストまとめ

| 期限 | 手続き | 届出先 |
|---|---|---|
| 7日以内 | 死亡届 | 市区町村役場 |
| 14日以内 | 年金受給権者死亡届 | 年金事務所 |
| 14日以内 | 健康保険・介護保険の資格喪失届 | 市区町村役場 |
| 14日以内 | 世帯主変更届 | 市区町村役場 |
| 3ヶ月以内 | 相続放棄・限定承認 | 家庭裁判所 |
| 4ヶ月以内 | 準確定申告 | 税務署 |
| 10ヶ月以内 | 相続税の申告・納付 | 税務署 |
| 1年以内 | 遺留分侵害額請求 | （相手方に通知） |
| 3年以内 | 相続登記 | 法務局 |

相続手続きは多岐にわたり、一人で進めるのは大変です。不安なときは、早い段階で専門家の力を借りることが、結果的にスムーズな解決への近道になります。
